edit_file 文件编辑工具

通过查找旧字符串并替换为新字符串来修改文本文件。文件使用 UTF-8 编码读写。

## 参数

- file_path（必填）：要编辑的文件路径。
- old_string（必填）：要被替换的字符串。必须在文件中存在，否则操作失败。
- new_string（必填）：替换后的新字符串。可以为空字符串（相当于删除 old_string）。
- replace_all（可选）：是否替换所有匹配项，默认 false（只替换第一个匹配项）。

## 返回值

返回一个 dict，包含以下字段：

- ok：是否成功（布尔值）。
- summary：操作摘要（字符串）。成功时说明替换了几处；失败时包含错误原因（文件不存在、字符串未找到等）。
- content：操作结果描述（字符串）。成功时为 "Successfully edited {file_path}"；失败时为空字符串。

## 输出示例（成功）

```json
{
  "ok": true,
  "summary": "Replaced 1 occurrence(s) of '00:00:05,000 --> 00:00:08,...' with '00:00:05,500 --> 00:00:09,...' in demo.srt",
  "content": "Successfully edited demo.srt"
}
```

## 输出示例（字符串未找到）

```json
{
  "ok": false,
  "summary": "String not found in demo.srt",
  "content": ""
}
```

## 注意事项

- old_string 必须与文件中的内容完全匹配，包括空格、换行符和标点。如果不确定文件内容，可先用 read_file 查看。
- replace_all 为 false 时，只替换文件中第一个匹配到的 old_string。
- 文件不存在时，ok 为 false，不会创建新文件。如需创建新文件，使用 write_file。
- 替换操作直接写回原文件，没有备份机制。
