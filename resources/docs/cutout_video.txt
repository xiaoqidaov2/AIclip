cutout_video 删除片段工具

从视频中删除指定时间范围的片段，将前后内容拼接成新文件。原文件不会被修改。

## 参数

- video_path（必填）：源视频文件路径。
- start（必填）：删除起始时间，单位为秒（浮点数）。
- end（必填）：删除结束时间，单位为秒（浮点数）。
- output_path（可选）：输出文件路径。若不指定，默认在源文件同目录下生成，文件名为原名加 _cutout 后缀，扩展名不变（例如 video.mp4 → video_cutout.mp4）。

## 返回值

返回一个 dict，包含以下字段：

- output_path：输出文件的完整路径（字符串）。
- source_path：规范化后的源文件路径（字符串）。
- operation：固定为 "cutout"。
- removed_range：被删除的时间区间，格式为 [start, end]（浮点数列表，秒）。
- duration：输出视频的总时长（浮点数，秒），等于原时长减去删除区间长度。

## 输出示例

```json
{
  "output_path": "C:/Users/admin/Videos/demo_cutout.mp4",
  "source_path": "C:/Users/admin/Videos/demo.mp4",
  "operation": "cutout",
  "removed_range": [30.0, 45.0],
  "duration": 110.36
}
```

## 约束与错误

- start 必须严格小于 end，否则抛出 ValueError: "start must be less than end"。
- end 不能超过视频总时长，否则抛出 ValueError: "end exceeds video duration"。

## 时间轴变化

删除操作完成后，输出视频的时间轴会整体压缩：原来位于 end 之后的所有内容，在输出文件中的时间点会向前移动 (end - start) 秒。例如，删除 30s–45s 后，原来 60s 处的内容在输出文件中变为 45s。

如果后续需要对输出文件进行基于时间的操作（如再次截取、烧录字幕），需要使用新的时间轴，而不是原始视频的时间轴。
