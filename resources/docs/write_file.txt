write_file 文件写入工具

将文本内容写入文件。文件不存在则创建，已存在则根据 overwrite 参数决定是否覆盖。自动创建父目录。使用 UTF-8 编码。

## 参数

- file_path（必填）：目标文件路径。
- content（必填）：要写入的文本内容（字符串）。
- overwrite（可选）：是否覆盖已存在的文件，默认 true。设为 false 时，若文件已存在则操作失败，不会修改原文件。

## 返回值

返回一个 dict，包含以下字段：

- ok：是否成功（布尔值）。
- summary：操作摘要（字符串）。成功时格式为 "Created {file_path} with N line(s)" 或 "Overwrote {file_path} with N line(s)"；失败时包含错误原因。
- content：操作结果描述（字符串）。成功时为 "Successfully wrote {file_path}"；失败时为空字符串。

## 输出示例（新建文件）

```json
{
  "ok": true,
  "summary": "Created C:/Users/admin/Videos/demo.srt with 20 line(s)",
  "content": "Successfully wrote C:/Users/admin/Videos/demo.srt"
}
```

## 输出示例（文件已存在且 overwrite=false）

```json
{
  "ok": false,
  "summary": "File already exists: C:/Users/admin/Videos/demo.srt",
  "content": ""
}
```

## 注意事项

- 父目录不存在时会自动创建（包括多级目录）。
- 写入内容使用 UTF-8 编码，适合中文文本。
- overwrite 默认为 true，即默认会覆盖已有文件，调用前需确认目标路径正确。
- 该工具写入整个文件内容，不支持追加写入。如需修改文件中的部分内容，使用 edit_file。
