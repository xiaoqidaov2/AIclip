grep_file 文件检索工具

在文件或目录中搜索匹配指定正则表达式的内容，返回匹配行及其所在文件和行号。不修改文件。

## 参数

- pattern（必填）：正则表达式模式（字符串）。使用 Python re 模块的语法。普通文本字符串也可以直接作为 pattern 使用（无需转义，除非包含正则特殊字符）。
- file_path（可选）：要搜索的文件或目录路径。若不指定，默认搜索当前工作目录（非递归，只搜索当前目录下的直接文件）。若指定为目录，同样只搜索该目录下的直接文件，不递归进入子目录。

## 返回值

返回一个 dict，包含以下字段：

- ok：是否成功（布尔值）。
- summary：操作摘要（字符串）。包含匹配数量或未找到的说明。
- content：匹配结果（字符串），格式为每行 "{文件路径}:{行号}: {行内容}"。最多返回 20 条匹配，超出部分会在末尾注明剩余数量。

## 输出示例（有匹配）

```json
{
  "ok": true,
  "summary": "Found 3 match(es) for pattern '00:00:0'",
  "content": "C:/Users/admin/Videos/demo.srt:2: 00:00:01,200 --> 00:00:04,800\nC:/Users/admin/Videos/demo.srt:6: 00:00:05,100 --> 00:00:08,300\n..."
}
```

## 输出示例（无匹配）

```json
{
  "ok": true,
  "summary": "No matches found for pattern 'ERROR'",
  "content": ""
}
```

## 注意事项

- 搜索使用 re.search，即只要行中任意位置匹配 pattern 即算命中，不要求整行匹配。
- 无法读取的文件（二进制文件、权限不足、编码错误）会被跳过，不影响其他文件的搜索。
- 目录搜索不递归，只处理直接子文件。如需递归搜索，可使用 bash_command 调用系统命令。
- 最多返回 20 条匹配结果，超出部分不会返回完整内容，只显示剩余数量。
