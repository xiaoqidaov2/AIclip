grep_file 文件检索工具

这个工具用于在文件或文本集合中查找指定模式，是定位信息的高效方式。它适合搜索关键词、路径、函数名、配置项、日志片段、错误信息或者特定文本结构。对于代码仓库或大型文本目录来说，grep_file 可以快速帮助你找到某个内容出现在哪个文件、哪一行附近，省去人工逐个打开文件的成本。它在自动化调试和代码理解中非常有用，因为很多时候你不是在读完整文件，而是在找“某个关键字到底在哪里出现”。

在协调器工作流中，grep_file 常用于探索项目结构、查找工具调用、定位配置项、确认某个资源是否存在。比如当你不确定字幕文件、字体路径或某个函数名时，可以先 grep 一下，再决定下一步操作。它适合做“发现线索”的工作，不负责修改，也不负责执行复杂命令。相比直接依赖 shell 搜索，它更容易被上层系统统一管理，且返回结果通常更便于后续分析。

使用时要注意搜索模式的精确度。普通文本查找适合已知字符串，正则查找适合复杂模式，但也更容易误命中。若需要检索大量文件，最好先限定目录范围，避免结果过多。grep_file 的价值在于快速缩小范围，让系统从“我不知道在哪里”变成“我已经知道目标文件的大致位置”。在排查问题、整理代码和构建自动化工作流时，它是很高频的辅助工具。
