bash_command Shell 命令工具

这个工具用于执行 shell 命令，适合在没有专用工具覆盖某个需求时作为补充手段。它的作用很广，可以做文件操作、目录查询、脚本运行、环境检查、简单文本处理，甚至调用外部程序。因为能力范围大，所以它通常是“最后手段”或“兜底工具”：如果已经有专门的 read_file、edit_file、grep_file、视频工具或字幕工具，优先用那些更安全、更明确的能力；只有在确实没有专用接口时，再使用 bash_command。

这个工具的优势是灵活，可以快速调用系统能力来完成临时任务。比如检查目录结构、生成临时脚本、执行 Python 片段、查询字体文件、验证文件是否存在，都可以通过它实现。它特别适合处理一些专用工具无法覆盖的细节问题。但正因为它太灵活，也更容易带来平台差异：Windows、PowerShell、WSL、cmd、bash 的命令写法并不完全一样，错误的命令会直接失败。所以在 AiClip 这类 Windows 环境中，必须优先考虑 Windows 命令或 Python 脚本，不要默认使用 Linux 命令。

使用时最重要的原则是谨慎和可控。命令要尽量短，尽量明确，避免一次塞入过多逻辑；涉及路径时要注意引号和空格；涉及文件写入时要确认目标路径安全。这个工具不是最安全的，但它是最通用的。对于自动化协调器来说，它像一把多用途工具刀，能补上专用工具之外的空白，但应该被严格约束使用范围。
