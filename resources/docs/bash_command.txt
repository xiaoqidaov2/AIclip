bash_command Shell 命令工具

执行 shell 命令并返回标准输出和标准错误。超时限制为 30 秒。

## 参数

- command（必填）：要执行的 shell 命令（字符串）。通过 shell=True 执行，支持管道、重定向等 shell 语法。

## 返回值

返回一个 dict，包含以下字段：

- ok：是否成功（布尔值）。命令退出码为 0 时为 true，非 0 时为 false。超时或执行异常时也为 false。
- summary：操作摘要（字符串）。包含退出码，或超时/异常信息。
- content：命令输出（字符串）。stdout 和 stderr 合并返回，stderr 部分以 "STDERR:" 分隔。输出超过 1000 字符时会被截断，末尾注明 "... (output truncated)"。

## 输出示例（成功）

```json
{
  "ok": true,
  "summary": "Command executed successfully (exit code 0)",
  "content": "demo.mp4\ndemo.srt\ndemo_subbed.mp4\n"
}
```

## 输出示例（命令失败）

```json
{
  "ok": false,
  "summary": "Command failed with exit code 1",
  "content": "STDERR:\n'ffmpeg' is not recognized as an internal or external command."
}
```

## 输出示例（超时）

```json
{
  "ok": false,
  "summary": "Command timed out after 30 seconds",
  "content": ""
}
```

## 平台注意事项

当前运行环境为 Windows。命令需使用 Windows 兼容的语法：

- 列出目录：`dir` 而非 `ls`
- 查看文件内容：`type filename` 而非 `cat filename`
- 路径分隔符：Windows 使用反斜杠 `\`，但 Python 路径字符串中通常用正斜杠 `/` 也可以
- 环境变量：`%VAR%` 而非 `$VAR`
- 如果在 WSL 环境中运行，则可以使用 Linux 命令

## 其他注意事项

- 命令在当前工作目录下执行。
- 输出编码使用 UTF-8，解码错误会被替换而不是抛出异常。
- 超时时间固定为 30 秒，无法调整。长时间运行的命令（如视频转码）不适合通过此工具执行。
