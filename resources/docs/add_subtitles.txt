add_subtitles 字幕烧录工具

将字幕文件硬编码到视频画面中，生成新文件。字幕成为画面的一部分，无法单独关闭。原文件不会被修改。

## 参数

- video_path（必填）：源视频文件路径。
- subtitle_path（必填）：字幕文件路径，支持 .srt 和 .vtt 格式。VTT 文件会在内部自动转换为 SRT 再进行烧录。
- font_path（必填）：字体文件路径（.ttf 或 .otf）。文件必须真实存在，否则抛出 ValueError。中文内容需确认字体支持中文字符，否则会出现方块字或渲染失败。
- output_path（可选）：输出文件路径。若不指定，默认在源文件同目录下生成，文件名为原名加 _subbed 后缀，扩展名不变（例如 video.mp4 → video_subbed.mp4）。
- font_size（可选）：字体大小，单位为像素，默认 36。
- color（可选）：字体颜色，默认 "white"。支持颜色名称（如 "yellow"、"black"）或十六进制值。
- position（可选）：字幕位置预设，默认 "bottom"。支持以下值：
  - top / bottom / center
  - left / right（垂直居中，靠左或靠右）
  - top_left / top_right / bottom_left / bottom_right
  - 别名：top_center、bottom_center、top_middle、bottom_middle、center_left、center_right、left_top、right_top、left_bottom、right_bottom
- margin_x（可选）：左右安全边距，单位像素，默认 0。影响 left、right、top_left、top_right、bottom_left、bottom_right 位置的水平偏移。
- margin_y（可选）：上下安全边距，单位像素，默认 48。影响 top、bottom 及四角位置的垂直偏移。
- x_offset（可选）：在 position 计算结果基础上的水平微调，单位像素，默认 0。正值向右，负值向左。
- y_offset（可选）：在 position 计算结果基础上的垂直微调，单位像素，默认 0。正值向下，负值向上。
- subtitle_box_width_ratio（可选）：字幕文本区域宽度占视频宽度的比例，默认 0.9，取值范围 0.1 到 1.0。超出范围抛出 ValueError。

## 返回值

返回一个 dict，包含以下字段：

- output_path：输出文件的完整路径（字符串）。
- source_path：规范化后的源文件路径（字符串）。
- subtitle_path：规范化后的字幕文件路径（字符串）。
- font_path：规范化后的字体文件路径（字符串）。
- position：实际使用的位置预设（字符串）。
- margin_x、margin_y、x_offset、y_offset：实际使用的边距和偏移值（整数）。
- subtitle_box_width_ratio：实际使用的字幕区域宽度比例（浮点数）。
- operation：固定为 "add_subtitles"。
- duration：输出视频的时长（浮点数，秒）。

## 位置计算逻辑

字幕区域的宽度 = 视频宽度 × subtitle_box_width_ratio。
字幕区域的高度估算为 font_size × 3。
position 预设决定字幕区域的基准坐标，margin_x/margin_y 控制与边缘的距离，x_offset/y_offset 在此基础上做像素级微调。

## 注意事项

- 字幕文件必须使用 UTF-8 编码，否则中文字符可能无法正确读取。
- 工具内部会将字幕文件复制到临时文件再处理，处理完成后自动清理临时文件。
- 烧录过程会重新编码视频，耗时与视频时长和分辨率成正比。
- 字幕文本超出 subtitle_box_width_ratio 定义的宽度时会自动换行。
