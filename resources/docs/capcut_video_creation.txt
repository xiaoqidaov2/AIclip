capcut_video_creation CapCut 视频生成工具

自动读取工程文件中的字幕数据，为视频添加特效、贴纸等视觉元素，并生成剪映草稿和最终视频。

重要提示：此工具必须在 render_project 工具被调用之后才能使用，因为它的 video_files 参数需要 render_project 返回的视频地址。此工具是整个工作流的最后一步。

## 参数

- project_path（必填）：工程文件路径（JSON 格式，包含 subtitles 字段）。
  获取方式：从 create_project_from_media 或 load_project 工具的返回结果中获取 state.project_path 字段的值。

- video_files（必填）：视频文件路径列表，例如：["C:/videos/v1.mp4"]
  获取方式：必须从 render_project 工具的返回结果中获取 state.final_path 或 artifacts[0].path 字段的值。
  例如：如果 render_project 返回 {"state": {"final_path": "C:/project/exports/final.mp4"}, ...}，则此参数应填 ["C:/project/exports/final.mp4"]。

- draft_name（可选）：剪映草稿名称，默认为 quick_video。

- max_effects（可选）：视频中允许添加的最大视觉特效数量，默认 5。

- max_stickers（可选）：视频中允许添加的最大贴纸数量，默认 3。

## 完整工作流示例

步骤 1: 创建工程并转写字幕。
调用 create_project_from_media，得到 state.project_path；调用 transcribe_audio 生成字幕。

步骤 2: 渲染项目生成最终视频。
调用 render_project，得到：
```json
{
  "ok": true,
  "state": {
    "final_path": "C:/project/exports/final.mp4",
    "project_path": "C:/project/project.json"
  },
  "artifacts": [
    {"type": "video", "path": "C:/project/exports/final.mp4"}
  ]
}
```

步骤 3: 调用 capcut_video_creation（最后一步）。
- project_path: 来自工程的 state.project_path。
- video_files: [来自 render_project 的 state.final_path]。

## 返回值

- ok（bool）：是否成功。
- draft_id：剪映草稿 ID。
- draft_path：剪映草稿保存路径。
- final_video_path：最终导出的视频文件路径。
- error（仅失败时）：错误信息。

## 注意事项

- 顺序约束：必须在调用 render_project 生成最终视频后，作为整个工作流的最后一步调用。
- 需要安装剪映专业版（Windows 版本）
- ASR 文件必须包含准确的时间戳信息
- 特效和贴纸数量受 max_effects 和 max_stickers 参数限制
- 首次运行可能需要初始化模型，耗时较长
