get_video_info 视频信息查询工具

读取视频文件的基础元数据，返回时长、帧率、分辨率和音轨信息。不修改文件，不产生任何输出文件。

## 参数

- video_path（必填）：视频文件的路径。路径中的多余引号和首尾空格会被自动清理。

## 返回值

返回一个 dict，包含以下字段：

- video_path：规范化后的视频文件路径（字符串）。
- duration：视频总时长，单位为秒（浮点数）。
- fps：帧率（浮点数），例如 30.0、25.0、29.97。
- size：分辨率，格式为 [宽, 高]（整数列表），例如 [1920, 1080]。
- has_audio：是否包含音轨（布尔值）。

## 输出示例

```json
{
  "video_path": "C:/Users/admin/Videos/demo.mp4",
  "duration": 125.36,
  "fps": 30.0,
  "size": [1920, 1080],
  "has_audio": true
}
```

## 注意事项

- duration 是浮点数，单位为秒。在传给 trim_video 或 cutout_video 时，end 参数不能超过这个值。
- has_audio 为 false 时，字幕生成工具（transcribe_audio、generate_subtitle_srt 等）将无法从该文件中提取语音。
- size 返回的是 [宽, 高] 顺序，即 [width, height]，在计算 crop_video 坐标或 add_subtitles 字幕位置时可以参考。
