resize_video 视频缩放工具

调整视频的分辨率，生成新文件。原文件不会被修改。

## 参数

- video_path（必填）：源视频文件路径。
- width（可选）：目标宽度，单位像素（整数）。
- height（可选）：目标高度，单位像素（整数）。
- scale（可选）：缩放比例（浮点数），例如 0.5 表示缩小到原来的一半，2.0 表示放大到两倍。
- output_path（可选）：输出文件路径。若不指定，默认在源文件同目录下生成，文件名为原名加 _resized 后缀，扩展名不变（例如 video.mp4 → video_resized.mp4）。

width、height、scale 三者至少提供一个，否则抛出 ValueError。

## 参数组合行为

- 仅提供 scale：按比例等比缩放，宽高同时乘以 scale 值。
- 仅提供 width：宽度设为指定值，高度保持原始值不变（不自动等比）。
- 仅提供 height：高度设为指定值，宽度保持原始值不变（不自动等比）。
- 同时提供 width 和 height：强制设置为指定宽高，不保证等比，可能导致画面拉伸。

## 返回值

返回一个 dict，包含以下字段：

- output_path：输出文件的完整路径（字符串）。
- source_path：规范化后的源文件路径（字符串）。
- operation：固定为 "resize"。
- original_size：原始分辨率，格式为 [宽, 高]（整数列表）。
- new_size：输出分辨率，格式为 [宽, 高]（整数列表）。

## 输出示例

```json
{
  "output_path": "C:/Users/admin/Videos/demo_resized.mp4",
  "source_path": "C:/Users/admin/Videos/demo.mp4",
  "operation": "resize",
  "original_size": [1920, 1080],
  "new_size": [960, 540]
}
```

## 注意事项

- 同时指定 width 和 height 但比例与原视频不一致时，画面会被拉伸变形。如需等比缩放到指定宽度，只传 width 并手动计算对应 height，或使用 scale 参数。
- 放大视频（scale > 1.0 或目标尺寸大于原始尺寸）会导致画质下降，因为像素信息无法凭空增加。
