concatenate_videos 视频拼接工具

按提供的顺序将多个视频文件拼接成一个输出文件。原文件不会被修改。

## 参数

- video_paths（必填）：视频文件路径的列表，按播放顺序排列。列表不能为空。
- output_path（可选）：输出文件路径。若不指定，默认在第一个输入文件的同目录下生成，文件名为第一个文件名加 _concat 后缀，扩展名不变（例如 a.mp4 → a_concat.mp4）。
- method（可选）：拼接方式，支持 "compose"（默认）或 "chain"。"compose" 会对不同尺寸的视频做合成处理；"chain" 要求所有输入视频的编码参数完全一致，速度更快但兼容性要求更高。

## 返回值

返回一个 dict，包含以下字段：

- output_path：输出文件的完整路径（字符串）。
- source_paths：所有输入文件的路径列表（字符串列表）。
- operation：固定为 "concatenate"。
- clip_count：输入视频的数量（整数）。
- duration：输出视频的总时长（浮点数，秒），等于所有输入视频时长之和。

## 输出示例

```json
{
  "output_path": "C:/Users/admin/Videos/part1_concat.mp4",
  "source_paths": [
    "C:/Users/admin/Videos/part1.mp4",
    "C:/Users/admin/Videos/part2.mp4",
    "C:/Users/admin/Videos/part3.mp4"
  ],
  "operation": "concatenate",
  "clip_count": 3,
  "duration": 185.4
}
```

## 注意事项

- 输入列表的顺序严格决定最终播放顺序，第一个文件的内容出现在最前面。
- 输入视频的分辨率、帧率、编码差异越大，输出结果越不稳定，可能出现画面抖动或音画不同步。如果素材规格差异较大，建议先用 resize_video 统一分辨率。
- 使用 "compose" 方法时，输出分辨率以第一个视频为基准，其他视频会被缩放或填充以适配。
- 使用 "chain" 方法时，所有输入视频必须具有完全相同的分辨率、帧率和编码参数，否则会出错。
