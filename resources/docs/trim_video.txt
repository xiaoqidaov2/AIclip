trim_video 截取视频工具

从视频中截取指定时间范围的片段，生成新文件。原文件不会被修改。

## 参数

- video_path（必填）：源视频文件路径。
- start（必填）：截取起始时间，单位为秒（浮点数）。
- end（必填）：截取结束时间，单位为秒（浮点数）。
- output_path（可选）：输出文件路径。若不指定，默认在源文件同目录下生成，文件名为原名加 _trimmed 后缀，扩展名不变（例如 video.mp4 → video_trimmed.mp4）。

## 返回值

返回一个 dict，包含以下字段：

- output_path：输出文件的完整路径（字符串）。
- source_path：规范化后的源文件路径（字符串）。
- operation：固定为 "trim"。
- start：实际使用的起始时间（浮点数，秒）。
- end：实际使用的结束时间（浮点数，秒）。
- duration：输出片段的时长（浮点数，秒），等于 end - start。

## 输出示例

```json
{
  "output_path": "C:/Users/admin/Videos/demo_trimmed.mp4",
  "source_path": "C:/Users/admin/Videos/demo.mp4",
  "operation": "trim",
  "start": 10.0,
  "end": 70.0,
  "duration": 60.0
}
```

## 约束与错误

- start 必须严格小于 end，否则抛出 ValueError: "start must be less than end"。
- end 不能超过视频总时长，否则抛出 ValueError: "end exceeds video duration"。
- 时间单位为秒，支持小数（例如 10.5 表示 10 秒 500 毫秒）。

## 注意事项

- 输出文件与源文件保持相同的视频编码和容器格式。
- 若 output_path 指定的父目录不存在，写入时会失败，需确保目录已存在。
- 若不确定视频总时长，可先调用 get_video_info 获取 duration 字段。
