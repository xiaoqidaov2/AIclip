read_file 文件读取工具

读取文本文件的完整内容并返回。不修改文件。

## 参数

- file_path（必填）：要读取的文件路径。

## 返回值

返回一个 dict，包含以下字段：

- ok：是否成功（布尔值）。
- summary：操作摘要（字符串）。成功时格式为 "Read N lines from {file_path}"；失败时包含错误原因。
- content：文件的完整文本内容（字符串）。失败时为空字符串。

## 输出示例（成功）

```json
{
  "ok": true,
  "summary": "Read 42 lines from C:/Users/admin/Videos/demo.srt",
  "content": "1\n00:00:01,200 --> 00:00:04,800\n今天我们来讲一下视频剪辑的基本流程。\n\n..."
}
```

## 输出示例（失败）

```json
{
  "ok": false,
  "summary": "File not found: C:/Users/admin/Videos/missing.txt",
  "content": ""
}
```

## 注意事项

- 文件使用 UTF-8 编码读取。如果文件实际编码不是 UTF-8，可能出现乱码或读取失败。
- 文件路径不存在时，ok 为 false，不会抛出异常。
- 该工具读取整个文件内容，对于非常大的文件（如几十 MB 的日志），返回内容可能很长。
