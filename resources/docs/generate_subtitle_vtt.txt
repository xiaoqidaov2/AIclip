generate_subtitle_vtt VTT 字幕生成工具

将音频或视频文件中的语音内容识别并生成 WebVTT 格式字幕文件，保存到磁盘。底层使用 faster-whisper 模型（base 规格，CPU 推理，int8 量化）。

## 参数

- audio_path（必填）：音频或视频文件的路径，支持 mp4、mp3、wav 等常见格式。
- language（可选）：语言代码，默认 "zh"（中文）。
- output_path（可选）：字幕文件的保存路径。若不指定，默认保存在与输入文件同目录、同名、扩展名为 .vtt 的位置（例如输入 video.mp4，输出 video.vtt）。

## 返回值

返回一个 dict，包含以下字段：

- subtitle：完整的 VTT 格式字幕文本内容（字符串）。
- format：固定为 "vtt"。
- segment_count：字幕段落数量（整数）。
- language：模型检测到的语言代码。
- output_path：字幕文件实际保存的完整路径。

## VTT 格式说明

VTT 文件以 "WEBVTT" 头部开始，后跟若干字幕块，每块包含：时间轴（HH:MM:SS.mmm --> HH:MM:SS.mmm）、字幕文本、空行。注意时间戳使用点号（.）而非逗号（,）。示例：

```
WEBVTT

00:00:01.200 --> 00:00:04.800
今天我们来讲一下视频剪辑的基本流程。

00:00:05.100 --> 00:00:08.300
首先需要准备好素材。
```

文件使用 UTF-8 编码，末尾保留一个空行。

## 注意事项

- 模型首次运行时需要下载权重文件，后续调用使用本地缓存。
- 识别质量受录音清晰度、噪声、口音等因素影响。
- output_path 的父目录若不存在会自动创建。
- add_subtitles 工具支持直接传入 .vtt 文件，内部会自动将其转换为 SRT 格式再进行烧录。
