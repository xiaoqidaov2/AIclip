crop_video 视频裁剪工具

裁掉视频画面的指定区域，只保留由坐标定义的矩形范围，生成新文件。原文件不会被修改。这是空间维度的裁剪（画面区域），不是时间维度的裁剪。

## 参数

- video_path（必填）：源视频文件路径。
- x1（必填）：裁剪框左边界的 x 坐标，单位像素，从画面左侧起算。
- y1（必填）：裁剪框上边界的 y 坐标，单位像素，从画面顶部起算。
- x2（可选）：裁剪框右边界的 x 坐标，单位像素。与 width 二选一，至少提供一个。
- y2（可选）：裁剪框下边界的 y 坐标，单位像素。与 height 二选一，至少提供一个。
- width（可选）：裁剪框的宽度，单位像素。等价于 x2 = x1 + width。
- height（可选）：裁剪框的高度，单位像素。等价于 y2 = y1 + height。
- output_path（可选）：输出文件路径。若不指定，默认在源文件同目录下生成，文件名为原名加 _cropped 后缀，扩展名不变（例如 video.mp4 → video_cropped.mp4）。

x2 和 width 至少提供一个；y2 和 height 至少提供一个，否则抛出 ValueError。

## 坐标系说明

坐标原点 (0, 0) 在画面左上角，x 轴向右增大，y 轴向下增大。例如，对于 1920×1080 的视频：
- 左上角：x1=0, y1=0
- 右下角：x2=1920, y2=1080
- 中心区域 960×540：x1=480, y1=270, width=960, height=540

## 返回值

返回一个 dict，包含以下字段：

- output_path：输出文件的完整路径（字符串）。
- source_path：规范化后的源文件路径（字符串）。
- operation：固定为 "crop"。
- original_size：原始分辨率，格式为 [宽, 高]（整数列表）。
- cropped_size：裁剪后的分辨率，格式为 [宽, 高]（整数列表）。
- crop_region：实际使用的裁剪参数，包含 x1、y1、x2、y2、width、height（未传入的字段值为 null）。

## 输出示例

```json
{
  "output_path": "C:/Users/admin/Videos/demo_cropped.mp4",
  "source_path": "C:/Users/admin/Videos/demo.mp4",
  "operation": "crop",
  "original_size": [1920, 1080],
  "cropped_size": [960, 540],
  "crop_region": {"x1": 480, "y1": 270, "x2": 1440, "y2": 810, "width": null, "height": null}
}
```

## 注意事项

- 坐标不能超出视频画面边界，否则会出错。
- x1 必须小于 x2（或 x1 + width 不能超出画面宽度），y1 必须小于 y2（或 y1 + height 不能超出画面高度）。
- 裁剪会改变视频的分辨率，输出视频的宽高等于裁剪框的宽高。
