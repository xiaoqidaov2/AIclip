# CapCut Finalization Skill

Use this skill only after the project has already been rendered.

Use it for post-render CapCut work:
- add effects
- add stickers
- create a CapCut draft from the final video
- package the output for short-form platforms
Do not use it for analysis, trimming, transcription, or timeline editing.

Trigger it only when the user explicitly asks for CapCut, 剪映, 草稿, 特效, 贴图, 贴纸, or post-render finishing.

Tools:
- `capcut_video_creation`
