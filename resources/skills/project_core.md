# Project Core Skill

Use this skill for project editing, subtitle work, timeline changes, validation, render prep, and export planning.

Prefer these tools in order:
- `load_project`
- `get_project_summary`
- `search_project_subtitles`
- `transcribe_audio`
- `remove_project_silence`
- `save_project`
- `prepare_project_render`
- `plan_project_export`
- `render_project`

Only use `batch_update_project_subtitles` when changing multiple subtitle cues at once.
If the user wants a stronger Douyin or short-video feel, treat hook strength, pacing, subtitle readability, and dead-air reduction as higher priority than decorative effects.
